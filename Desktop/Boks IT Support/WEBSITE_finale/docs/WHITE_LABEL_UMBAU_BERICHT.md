## Was bewusst nicht geändert wurde

- Visuelles Design / CSS / Layout-System

- Rechtliche Identität Einzelunternehmen  
- Basischeck CHF 190 als etablierter Richtwert  
- Pilot-/Einführungsbanner (Zustand A)
