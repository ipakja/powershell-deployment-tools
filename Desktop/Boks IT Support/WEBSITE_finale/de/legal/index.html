Datenschutz

Auf dieser Website steht ein Anfrageformular für die Bedarfsabklärung zur Verfügung. Wenn Sie das Formular absenden, werden die von Ihnen eingegebenen Angaben verarbeitet, damit BIT Ihren Bedarf einschätzen und Sie kontaktieren kann. Alternativ erreichen Sie BIT per E-Mail, Telefon oder WhatsApp.

Erhobene Datenkategorien

  • Unternehmen
  • Vor- und Nachname
  • Geschäftliche E-Mail-Adresse
  • Anzahl Mitarbeitende
  • Gewünschter Leistungsbereich
  • Kurze Problembeschreibung
  • Telefonnummer (optional)
  • Standort / Kanton (optional)
  • Branche (optional)
  • Anzahl Arbeitsplätze (optional)
  • Angaben zu Microsoft 365 sowie zur internen und externen IT-Situation (optional)
  • Gewünschter Startzeitpunkt (optional)
  • Technische Metadaten der Übermittlung (z. B. Zeitpunkt, Request-ID; ggf. IP-Land über den Hosting-Anbieter)

Zweck der Verarbeitung

Bedarfsabklärung: Prüfung, ob und in welchem Rahmen eine Zusammenarbeit möglich ist, sowie Kontaktaufnahme zur Einschätzung.

Rechtsgrundlage

Einwilligung. Sie erteilen sie über die Pflicht-Checkbox im Anfrageformular vor dem Absenden.

Aufbewahrungsdauer

Anfragen werden höchstens zwölf Monate gespeichert und danach gelöscht, sofern keine gesetzlichen Aufbewahrungspflichten oder berechtigten Gründe für eine längere Speicherung bestehen.

Empfänger und Auftragsverarbeiter

Das Anfrageformular wird über die Website an einen Cloudflare-Endpunkt übermittelt. Die Angaben werden dort für die Bedarfsabklärung gespeichert (Cloudflare KV) und an admin@boksitsupport.ch per E-Mail weitergeleitet (Versanddienst Resend, sofern aktiv). Hosting der Website: Cloudflare Pages. Cloudflare und ggf. Resend können Server ausserhalb der Schweiz betreiben.
