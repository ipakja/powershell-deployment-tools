When it is unclear which accounts and access rights are still active.

When it is unclear which accounts and rights are still active, you need a written overview first — not an open-ended engagement. The IT basics check is a clearly scoped entry: review access, prioritise risks, deliver a finding. Result first: a documented finding with priorities before further steps are agreed. From CHF 190 as a fixed-price entry. The check creates a decision base: what first, what later, what sits outside the agreed scope. Remote is usual; Zurich-area on-site only when needed and listed separately. Not a security audit and not an unlimited follow-on engagement.

Typical situations

  • Unclear which accounts and rights are still active.
  • You want a written overview before further steps.
  • A clearly scoped entry matters more than an open-ended engagement.
  • Before a staffing change or a tool decision, a shared overview of active access is missing.

Process

  • 1Capture the starting point and access overview
  • 2Record checked points and findings
  • 3Formulate priorities and next steps
  • 4Deliver the written finding

Required details

  • Approximate number of employees and workstations
  • Whether Microsoft 365 is in use
  • Known access or permission questions

Boundaries

The basics check is not a cybersecurity audit and not a penetration test. Specialist technical execution only after prior agreement with a suitable specialist. The finding is a priority overview, not a guarantee of completeness across every system and not approval for technical changes without a written follow-on agreement.

For the basics check, use the inquiry form with IT basics check preselected. Submitting the form does not create an engagement.
